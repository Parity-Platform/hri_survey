# Participatory workshop facilitation guide

HRIT ran three workshops with 15 or more participants each: one on the production floor of a manufacturing SME and two at a neutral venue (the University of Patras). Each mixed workers, operators, supervisors, clients and community participants.

## Roles

| Role | Task |
|---|---|
| Facilitator | Neutral, not in the participants' line management; runs the agenda and protects equal participation |
| Co-facilitator | Tracks speaking time and representation; supports small groups |
| Note taker | Records discussion without names, only participant codes and groups |
| Company contact | Answers factual questions on plans; does not lead discussion |

## Materials

- Printed one-page summary of survey and interview results, with charts from the dashboards
- Sticky notes in two colours, markers, dot stickers
- Flip charts with the headings: Benefits, Risks, Conditions, Questions
- Speaking-time tally sheet (see below)
- Attendance sheet with participant code, group, gender and age band only

## Agenda (3 hours)

| Time | Block | Method |
|---|---|---|
| 0:00 | Welcome and ground rules | Purpose, confidentiality, no decision taken yet; agree rules: one voice at a time, criticise ideas not people, everyone speaks before anyone speaks twice |
| 0:15 | Results walk | Facilitator presents the one-page summary; participants add notes to the four flip charts |
| 0:45 | Misconceptions check | Short demonstration or video of the robot type considered; open questions on what it can and cannot do |
| 1:15 | Break | |
| 1:30 | Small-group discussion | Groups of 4 to 6, mixed by role; each group answers: "Under what conditions would this change be acceptable?" |
| 2:15 | Principles drafting | Groups report back; facilitator clusters conditions into draft principles |
| 2:40 | Prioritisation | Each participant places three dots on the principles that matter most |
| 2:50 | Next steps | Explain how results will be published and when participants will hear back |

## Inclusive facilitation methods

- **Silent writing first.** Participants write their views on notes before any open discussion, so that seniority does not set the tone.
- **Round robin.** Each person speaks in turn on key questions; passing is allowed.
- **Mixed small groups.** Supervisors and their own team members are placed in different groups.
- **Language support.** Provide materials and, where needed, an interpreter for every language spoken by at least 10% of participants.
- **Accessible timing.** Schedule within paid working time and across shifts; provide a second session for night shift staff if needed.

## Speaking-time tracking

The co-facilitator records, per block, the approximate speaking minutes by group. Publish the totals with the workshop report.

| Block | Workers | Operators | Supervisors / managers | Clients | Community | Women | Men |
|---|---|---|---|---|---|---|---|
| Results walk | | | | | | | |
| Small groups (report back) | | | | | | | |
| Principles drafting | | | | | | | |

If one group exceeds 40% of speaking time in a block, the facilitator invites the other groups first in the next block.

## Workshop report structure

1. Date, venue, number of participants by group, gender and age band
2. Main points per flip chart heading
3. Draft principles and dot-vote ranking
4. Open questions addressed to the company
5. Speaking-time totals

Circulate the report to participants for comment within two weeks, then merge it into the synthesis report.
